# 学情プラス

**新潟大学の学務情報システム（学情）を、スマホでもパソコンでも使いやすくするブラウザ拡張機能です。**

ログインすると、学情の画面が見やすい新しい画面に切り替わります。課題の締切、未読の連絡、成績、時間割を1か所で確認できます。

> [!IMPORTANT]
> **新潟大学の公式のものではありません。** 学生が個人で作っている非公式の拡張機能です。大学や学情の運営元に問い合わせないでください。困ったときは [Issues](https://github.com/WVYYYVW/niigata-gakujo-plus/issues) へどうぞ。

## まずはここから：あなたの端末での入れ方

| 使っている端末 | 使うブラウザ | 入れ方 | かかる時間 |
|---|---|---|---|
| 📱 **Android のスマホ・タブレット** | Firefox（無料） | アドオンのページで「追加」を押すだけ | 約3分 |
| 📱 **iPhone・iPad** | Orion（無料） | アドオンのページで「追加」を押すだけ（※試験的な対応） | 約5分 |
| 💻 **パソコン**（Windows・Mac） | Firefox | アドオンのページで「追加」を押すだけ | 約2分 |
| 💻 **パソコン**（Windows・Mac） | Chrome・Edge・Vivaldi・Brave | ファイルをダウンロードして読み込む | 約5分 |

- **いちばん簡単なのは Firefox です。** スマホでもパソコンでも、ボタン1つで入って自動で更新されます。
- **Firefox アドオンのページ：** https://addons.mozilla.org/ja/firefox/addon/niigata-gakujo-plus/
  （いま公開の審査中です。ページが開けないときは、少し待ってからもう一度お試しください）
- Android の Chrome と、iPhone・iPad の Safari・Chrome では使えません（それらのブラウザが、この種類の拡張機能に対応していないためです）。

## できること

| 画面 | できること |
|---|---|
| 🏠 **ホーム** | 今日・明日の予定、今週の締切、締切が近い課題、未読の連絡がひと目でわかる |
| 📝 **課題** | レポート・小テスト・アンケートを締切順に一覧。残り時間を色分け（24時間以内は赤）。自分用の締切・進み具合・メモ。カレンダーへの書き出し |
| ✉️ **連絡** | 未読・種類別（試験の連絡など）の一覧、並べ替え、検索。一括で既読。**添付ファイルをまとめて zip で保存** |
| 📅 **予定** | 学情のスケジュール、休講・補講・教室変更。医学科は講義概要の授業日程も |
| 📚 **授業** | 時間割、履修中の科目、出欠、シラバス、フォーラム。科目ごとのページ（課題・成績・出欠・連絡をまとめて表示） |
| 🎓 **成績** | 修得単位、平均点、GPA（参考値）、成績の見通し（仮の点数で試算） |
| ⏱ **自動延長** | ログイン時間（20分）が切れる前に自動で延長。延長を続ける時間は設定で変えられる |
| 🔐 **2段階認証** | 鍵を登録しておくと、認証コードを自動で入力して送信 |
| 🔎 **検索** | 画面上の虫めがねで、課題・連絡・科目・成績をまとめて検索 |

- レポートの提出、履修登録などの**書き込みは、学情本来の画面**で行います（二重提出などの事故を防ぐため）。その画面も、新しい画面の中に開きます。
- 右上の「⇄」ボタンで、**いつでも元の学情の画面に戻せます。**

## 入れ方（端末別のくわしい手順）

見出しをタップ（クリック）すると、手順が開きます。

<details>
<summary><b>📱 Android のスマホ・タブレット（Firefox）</b></summary>

### 1. Firefox を入れる
1. **Google Play** を開き、「**Firefox**」と検索します。
2. 「Firefox 高速でプライベートなブラウザ」（提供元：Mozilla）を**インストール**します。

### 2. 学情プラスを入れる
1. **Firefox で**このページを開きます：
   https://addons.mozilla.org/ja/firefox/addon/niigata-gakujo-plus/
   （Chrome など、ほかのブラウザで開いても入れられません。リンクを長押しして「コピー」し、Firefox のアドレス欄に貼り付けると確実です）
2. 「**Firefox へ追加**」をタップします。
3. 「学情プラス を追加しますか？」と、使う権限の説明が出ます。「**追加**」をタップします。
   - 「gakujo.iess.niigata-u.ac.jp のデータへのアクセス」は、学情の画面を読み込むために必要な権限です。ほかのサイトにはアクセスしません。
4. 「プライベートウィンドウでの実行を許可」は、オフのままで構いません。

### 3. 学情を開く
1. Firefox で学情（https://gakujo.iess.niigata-u.ac.jp/campusweb/）を開き、いつもどおりログインします。
2. 新しい画面が表示されれば完了です 🎉
3. **ホーム画面に追加しておくと便利です**：Firefox の右下（または右上）の「︙」→「ホーム画面に追加」で、アプリのように1タップで開けます。

### うまくいかないとき
- **「追加」ボタンが出ない**：Firefox のアプリを最新版に更新してください（Google Play →「Firefox」→「更新」）。
- **新しい画面にならない**：Firefox の「︙」→「拡張機能」→「拡張機能の管理」で、学情プラスがオンになっているか確認してください。

</details>

> [!NOTE]

### 1. Orion を入れる
1. **App Store** を開き、「**Orion Browser**」と検索します。
2. 「Orion Browser by Kagi」を**入手**します（無料です）。

### 2. 拡張機能を使えるようにする
1. Orion を開き、画面の「**•••**」（iPhone は右下、iPad は右上）をタップします。
2. 「**設定**」→「**拡張機能**」の項目で、「**Firefox 拡張機能**」をオンにします。

### 3. 学情プラスを入れる
1. **Orion で**このページを開きます：
   https://addons.mozilla.org/ja/firefox/addon/niigata-gakujo-plus/
2. 「**Firefox へ追加**」（または「インストール」）をタップし、確認が出たら許可します。
3. 「•••」→「**拡張機能**」の一覧に学情プラスがあれば完了です。

### 4. 学情を開く
1. Orion で学情を開き、ログインします。
2. 新しい画面が表示されれば完了です 🎉
3. 共有ボタン →「ホーム画面に追加」で、アプリのように開けます。

</details>

1. Firefox でこのページを開きます：
   https://addons.mozilla.org/ja/firefox/addon/niigata-gakujo-plus/
2. 「**Firefox へ追加**」→「**追加**」を押します。
3. 学情を開いてログインすると、新しい画面が表示されます。

更新は自動で行われます。

<details>
<summary><b>💻 パソコンの Chrome・Edge・Vivaldi・Brave（Windows・Mac）</b></summary>

これらのブラウザでは、いまはストアで公開していないため、**ファイルをダウンロードして読み込む**方法で入れます。少し手順が多いですが、1つずつ進めれば大丈夫です。

### 1. ファイルをダウンロードする
1. [リリースのページ](https://github.com/WVYYYVW/niigata-gakujo-plus/releases/latest) を開きます。
2. 「Assets」の中の **`gakujo-plus-chrome-（バージョン）.zip`** をクリックしてダウンロードします。
   - 名前に `firefox` や `safari` が付いたファイルではなく、`chrome` のファイルを選んでください（Edge・Vivaldi・Brave も同じ `chrome` 用です）。

### 2. ファイルを展開して、置き場所を決める
1. ダウンロードした zip を展開します。
   - **Windows**：zip を右クリック →「**すべて展開**」→「展開」
   - **Mac**：zip をダブルクリック
2. できたフォルダを、**消さない場所**（「ドキュメント」フォルダなど）に移します。
   - ⚠️ ブラウザはこのフォルダから学情プラスを読み込みます。**フォルダを消したり移動したりすると、学情プラスが動かなくなります。**

### 3. ブラウザに読み込む
1. アドレス欄に次のように入力して開きます。

   | ブラウザ | 入力するアドレス |
   |---|---|
   | Chrome | `chrome://extensions` |
   | Edge | `edge://extensions` |
   | Vivaldi | `vivaldi://extensions` |
   | Brave | `brave://extensions` |

2. 「**デベロッパー モード**」（Edge は「**開発者モード**」）をオンにします。
   - Chrome・Vivaldi・Brave：画面の右上
   - Edge：画面の左側（見つからないときは左上の「≡」から）
3. 「**パッケージ化されていない拡張機能を読み込む**」（Edge は「**展開して読み込み**」）を押します。
4. 手順2で置いたフォルダを選びます。**`manifest.json` が入っているフォルダ**を選ぶのがポイントです。
5. 一覧に「学情プラス」が出れば完了です。
6. 右上のパズルのアイコン →「学情プラス」の📌を押すと、ツールバーに固定できます（設定を開きやすくなります）。

### 4. 学情を開く
学情を開いてログインすると、新しい画面が表示されます 🎉

### 注意
- ブラウザを起動したときに「デベロッパー モードの拡張機能を無効にする」と表示されることがあります。**「無効にする」は押さずに**、×で閉じてください。
- **更新は自動では行われません。** 新しいバージョンが出たら、[更新のしかた](#更新のしかた)を見てください。

</details>

<summary><b>🍎 Mac の Safari</b></summary>

いまは対応していません。Safari の拡張機能は App Store での配布が必要なためです。Mac では Firefox か Chrome をお使いください。

### 更新のしかた

| 入れ方 | 更新のしかた |
|---|---|
| Firefox・Orion（アドオンのページから入れた場合） | **自動で更新されます。** 何もしなくて大丈夫です |
| Chrome・Edge・Vivaldi・Brave（ファイルから読み込んだ場合） | 1. [リリースのページ](https://github.com/WVYYYVW/niigata-gakujo-plus/releases/latest) から新しい zip をダウンロードして展開する<br>2. **前のフォルダの中身を、新しいフォルダの中身で置き換える**（フォルダの場所は変えない）<br>3. 拡張機能のページ（`chrome://extensions` など）で、学情プラスの「↻（再読み込み）」を押す |

更新しても、設定・2段階認証の鍵・メモは消えません（Chrome などでフォルダの場所を変えた場合は消えることがあります）。

### やめたいとき（アンインストール）

- **Firefox・Orion**：拡張機能の一覧で学情プラスを選び、「削除」
- **Chrome など**：拡張機能のページで学情プラスの「削除」→ そのあと、置いていたフォルダも削除

削除すると、学情プラスがこの端末に保存した内容（設定・鍵・メモ・講義概要）はすべて消えます。

## 使い方の基本

1. **ログイン**：学情を開くと、ログイン画面も新しいデザインになります。いつもの学籍番号とパスワードでログインします。
2. **新しい画面**：ログインすると自動で新しい画面になります。下（パソコンは左）のメニューで、ホーム・課題・連絡・予定・授業・成績を切り替えます。
3. **元の学情の画面に戻す**：右上の「⇄」を押します。新しい画面に戻るときは、右下の「新しい画面」ボタンを押します。
4. **設定**：右上の⚙️から開きます。
   - 新しい画面を使うかどうか、テーマ（ダークモード）
   - ログイン時間の自動延長（何分前に延長するか、何時間まで続けるか）
   - 2段階認証の自動入力
   - 医学科モード
   - 診断（学情の仕様が変わって動かないときの確認用）
5. **連絡を開くと既読になる**のは学情と同じです。一括既読は確認が出てから実行します（学情には「未読に戻す」機能がありません）。

## 2段階認証の自動入力を設定する

ログインのたびに認証アプリを開いて6桁のコードを入力する手間をなくす機能です。**使わなくても、ほかの機能は使えます。**

> [!WARNING]
> **この機能を使うと、その端末だけでログインできる状態になります。**
> 2段階認証は「パスワード ＋ 手元の認証アプリ」の2つで本人確認をするしくみです。この機能はその片方を端末に任せるので、**自分専用の端末だけ**で使ってください。家族や友人と共用しているパソコンでは使わないでください。

### しくみ
2段階認証の設定のとき、学情は QR コードと一緒に「**鍵**」（英大文字と数字の長い文字列）を表示します。認証アプリは、この鍵から6桁のコードを作っています。同じ鍵を学情プラスにも登録すれば、学情プラスが同じコードを作って入力できます。鍵はその端末のブラウザの中だけに保存し、どこにも送信しません。

**鍵は2段階認証を設定する画面でしか表示されません。** すでに設定済みの人は、いったん2段階認証をリセットして、設定をやり直す必要があります。

### 手順（すでに2段階認証を設定している人）

#### ステップ1：2段階認証をリセットする
1. 学情にログインし、2段階認証の画面（6桁のコードを入力する画面）まで進みます。
2. 画面の「**リセット**」を押します。
3. 2〜3分ほどで、大学のメールアドレス（学籍番号のアドレス）に **system@mail.cc.niigata-u.ac.jp** から「**【セキュリティキーリセット】**」というメールが届きます。
4. メールのリンクを開き、「**リセット**」→ 確認画面で「**OK**」を押します。
   - この時点で、認証アプリに登録していた古い「学情」は使えなくなります。認証アプリから削除して構いません。
5. いつものログイン画面に戻るので、ログインします。

#### ステップ2：新しい鍵を登録する
ログインすると、2段階認証の**設定画面**（QR コードが表示される画面）になります。

1. **まず、QR コードを認証アプリ（Google Authenticator など）で読み取ります。**
   - 学情プラスが使えないときの予備として必ず登録してください。
2. 画面の下に「**学情プラス：2段階認証の自動入力を設定**」という枠が表示されます。
   - 鍵が自動で入力されていれば、そのまま「**学情プラスに登録**」を押します。
   - 空欄のときは、画面に表示されている鍵をコピーして貼り付けてから押します。
3. 「登録しました。いまのコード：123456」のように表示されます。**このコードが認証アプリのコードと同じか確かめてください。**
4. 同じなら、学情の「**認証**」ボタンを押して設定を完了します。

#### ステップ3：次回からのログイン
学籍番号とパスワードでログインすると、認証コードが**自動で入力され、送信されます。**
- 自動で送信せず、入力だけにしたい場合は、設定の「自動で送信して認証を通過」をオフにします。
- 失敗が続かないよう、自動送信は1分に1回までにしています。

### 手順（まだ2段階認証を設定していない人）
上の「ステップ2」から始めてください。

### 複数の端末で使う場合
**すべての端末に同じ鍵を登録する**必要があります。端末ごとに設定をやり直すと、そのたびに鍵が変わり、前の端末で登録した鍵が使えなくなります。

- 鍵は**パスワード管理アプリなど安全な場所**に控えておくと、ほかの端末に登録するときに便利です。
- 2台目以降の端末では、学情プラスの設定（⚙️）→「2段階認証」の欄に、控えておいた鍵を貼り付けて「保存」します。
- 鍵を人に見せたり、LINE やメールで送ったりしないでください。

### うまくいかないとき
- 設定（⚙️）→「2段階認証」に、いまのコードが表示されます。**認証アプリのコードと違う場合**は、鍵が間違っているか、そのあと2段階認証がリセットされています。正しい鍵を登録し直してください。
- 端末の**時計がずれている**と、コードが合いません。端末の日時を「自動設定」にしてください。
- 鍵を削除したいときは、設定（⚙️）→「2段階認証」→「削除」を押します。

## 医学科モード（講義概要の授業日程）

医学部医学科では、授業日程が「講義概要」の PDF で配布されます。この PDF を学情プラスに取り込むと、自分の学年の授業日程を「予定」とホームに表示できます。

- 学情の所属（医学部医学科）と学年から、**自動で医学科モードになります。** 設定（⚙️）→「医学科モード」で、オン・オフや学年を変えられます。
- **取り込み方**：「予定」の「授業日程」→「講義概要の PDF を取り込む」→ 大学から配布された PDF を選ぶ →「この内容で保存する」
- **カレンダーに書き出す**：「予定」の「カレンダーに書き出す」で、今日以降の授業日程を .ics ファイルにして保存します。iPhone・Android・Google カレンダーなどに取り込めます。
- **講義概要（シラバス）**：「授業」→「講義概要」で、科目ごとの講義概要を**原本の PDF のページのまま**表示します。本文の検索もできます。

### 間違った日程を表示しないための工夫
- **すべての予定に PDF のページ番号を付けています。**「p.14」などを押すと原本のページが開くので、いつでも確かめられます。
- PDF の文字と罫線から読み取ったうえで、**ページを画像にして罫線の位置をもう一度確認**しています。少しでも食い違う週や、読み取れない文字がある週は表示せず、「原本で確認」を案内します。
- **年度が変わると、古い講義概要の日程は表示しません。** 新年度の講義概要を取り込んでください。
- 取り込んだあとに「講義概要」「時間割」についての連絡が届くと、修正版が出た可能性をお知らせします。
- **休講・補講・教室変更は、学情の連絡と「休講・補講」が優先です。** 講義概要は配布時点の予定です。

### 講義概要の取り扱い
- PDF は**端末の中だけで読み取り**、どこにも送信しません。
- 講義概要の著作権は新潟大学にあります。**取り込んだ PDF や、書き出したカレンダーのファイルをほかの人に配らないでください。**

## よくある質問

<details>
<summary><b>Q. 学籍番号やパスワードを盗まれたりしませんか？</b></summary>

学情プラスは学籍番号もパスワードも保存しません。ログインは学情の画面で行い、学情プラスは見た目を変えているだけです。通信先は学情（gakujo.iess.niigata-u.ac.jp）だけで、ほかのサーバーには一切送信しません。ソースコードはすべてこのページで公開しています。

</details>

<details>
<summary><b>Q. 元の学情の画面も使えますか？</b></summary>

右上の「⇄」で、いつでも元の画面に切り替えられます。新しい画面を使わない設定にもできます（設定 →「新しい画面を使う」をオフ）。

</details>

<details>
<summary><b>Q. 似た拡張機能（More-Better-Gakujo など）と一緒に使えますか？</b></summary>

おすすめしません。同じ画面を書き換えたり、2段階認証のコードを二重に入力したりして、うまく動かないことがあります。**どれか1つだけ**を有効にしてください。学情プラスは More-Better-Gakujo の機能をすべて含んでいます。

</details>

<details>
<summary><b>Q. 急に動かなくなりました</b></summary>

学情の仕様が変わった可能性があります。
1. 右上の「⇄」で元の画面に戻れば、学情は普段どおり使えます。
2. 設定（⚙️）→「診断」→「診断を実行」で、どこが読めなくなったかを確認できます。
3. 「結果をコピー」して [Issues](https://github.com/WVYYYVW/niigata-gakujo-plus/issues) に貼り付けてもらえると、修正の助けになります（診断結果に個人情報は含まれません）。

</details>

<details>
<summary><b>Q. 連絡を開いただけで既読になります</b></summary>

学情の仕様です（本文を開くと既読になります）。学情プラスは、本文を開く操作と、確認のうえで行う一括既読・添付のまとめて保存のとき以外は、既読にしないように作っています。

</details>

<details>
<summary><b>Q. 英語表示（English）でも使えますか？</b></summary>

学情を英語表示にしていると、一部の画面を読み取れません。その場合は画面にお知らせが出るので、学情の表示を日本語に切り替えてください。

</details>

## 安全性とプライバシー

| 保存するもの | 保存場所 | 送信先 |
|---|---|---|
| 設定 | ブラウザ（同じアカウントの別端末と同期されることがあります） | なし |
| 2段階認証の鍵 | この端末のブラウザの中だけ（同期しません） | なし |
| 課題のメモ・ピン留め・下書き | この端末のブラウザの中だけ | なし |
| 取り込んだ講義概要（PDF と読み取り結果） | この端末のブラウザの中だけ | なし |

- 学籍番号・パスワードは保存しません。
- 通信するのは学情（https://gakujo.iess.niigata-u.ac.jp/）だけです。広告・アクセス解析などは一切入っていません。
- くわしくは [プライバシーポリシー](PRIVACY.md) を見てください。

## 開発者向け

<details>
<summary>ビルド・テスト・構成</summary>

ひとつのソースコード（`src/`）から、Chrome・Firefox・Safari 向けの拡張機能を出力します。

```bash
npm install        # テスト用の jsdom と、医学科モード用の pdf.js を取得
npm test           # 読み取り処理の自動テスト（学情を模した架空の HTML で確認）
node build.mjs     # dist/chrome, dist/firefox, dist/safari と各 zip を出力
```

| フォルダ | 内容 |
|---|---|
| `src/common/` | ブラウザの違いの吸収、設定、TOTP、学情の画面の読み取り |
| `src/content/` | 新しい画面、ログイン画面、2段階認証、自動延長、旧画面の改善 |
| `src/med/` | 医学科モード（講義概要 PDF の読み取り・原本の表示） |
| `src/vendor/pdfjs/` | pdf.js 4.10.38（legacy build、改変なし） |
| `src/options/` | 設定ページ |

- 学情の画面に依存する処理は `src/common/gakujo.js` にまとめています。学情の仕様が変わったときは、まずここを確認してください。
- 連絡の本文を開くページ（`_eventId=displayMidoku` など）は既読になるため、本文を開く操作以外からは読み込めないようにしています。
- Pull Request・Issue を歓迎します。テストには架空のデータだけを使い、実際の学情の画面や個人情報、講義概要の PDF はコミットしないでください。

</details>
